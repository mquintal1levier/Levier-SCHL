# Palette et style visuel Levier

Basé sur les présentations Levier existantes et le Guide de normes SCHL (branding Levier).

## Palette

| Rôle | Couleur | Hex |
|---|---|---|
| Primaire (fonds foncés, en-têtes de tableau) | Vert forêt charcoal | `1F2E28` |
| Secondaire (bordures, éléments neutres) | Taupe chaud | `8A8168` |
| Accent (chiffres clés, kickers) | Or / taupe doré | `B08D57` |
| Fond de carte / bloc de contenu | Neutre très clair | `F2F1EC` |
| Texte principal | Vert forêt charcoal | `1F2E28` |
| Texte atténué | Gris-taupe | `6B6B63` |
| Blanc | — | `FFFFFF` |

## Typographie

- Titres de diapositive et gros chiffres : police serif (Cambria) — cohérent avec le logo Levier ("— Levier", empattements).
- Corps de texte, tableaux, légendes : police sans-serif (Calibri).
- Kicker de section (ex. "LE PROJET", "L'EMPRUNTEUR", "LE FINANCEMENT") : petite majuscule, espacement de caractères large, couleur accent.

## Structure visuelle

- Fond blanc pour les diapositives de contenu.
- Fond vert forêt (`1F2E28`) pour la page titre et la diapositive de clôture — texte blanc, accent or pour les chiffres/labels clés.
- Cartes de contenu (roundRect) en fond `F2F1EC` pour regrouper de l'information sans utiliser de bandes de couleur ou de bordures latérales.
- En-têtes de tableau : fond `1F2E28`, texte blanc, appliqué directement sur les cellules d'en-tête (jamais via un rectangle superposé après coup — ça masque le texte).
- Jamais de barre d'accent sous les titres ni de bande latérale décorative — utiliser l'espace blanc ou le fond de carte pour distinguer les sections.

## Éléments récurrents observés

- Logo "— Levier / AGENCE IMMOBILIÈRE" en bas de la page titre.
- Pied de page sur les diapositives de contenu : nom du projet/adresse à gauche, numéro de page à droite.
- Organigrammes de structure d'emprunt : boîtes reliées par des lignes, avec le % de détention et le type de caution (corporative/personnelle) inscrits dans chaque boîte.
- Tableaux "Détails de la force financière" : une ligne par entité/caution, colonnes Valeur totale / Terrain / Liquidités / Parc immobilier / Commentaires.
